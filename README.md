# Messenger Revival

Proyecto independiente creado para revivir la experiencia social de los mensajeros instantáneos de principios de los 2000: contactos, estados, conversaciones, emoticonos, alertas y el mítico “zumbido”, reinterpretados para la web actual.

> Este proyecto es un tributo no oficial inspirado en la era de MSN Messenger / Windows Live Messenger. No está afiliado ni respaldado por Microsoft y no utiliza recursos gráficos, logotipos ni sonidos propietarios de Microsoft.

## Objetivo

Quiero recuperar la sensación de abrir el Messenger clásico: ver quién está conectado, cambiar mi estado, iniciar conversaciones y sentir que la aplicación está viva. La interfaz busca ser nostálgica, pero el código y la arquitectura son modernos.

## Primera versión

- Interfaz web responsive inspirada en mensajería de los años 2000.
- Lista de contactos con estados Disponible, Ausente y Ocupado.
- Ventana de conversación.
- Alias configurable.
- Emoticonos.
- Zumbido visual.
- Mensajes persistentes en el navegador mediante `localStorage`.
- Sin dependencias: HTML, CSS y JavaScript puro.

## Próximas etapas

1. Backend en tiempo real.
2. Usuarios anónimos con apodo.
3. Presencia y contador de personas conectadas.
4. Historial persistente en base de datos.
5. Salas públicas y conversaciones privadas.
6. Moderación, límites anti-spam y reportes.
7. Sonidos originales creados específicamente para el proyecto.
8. Despliegue público.

## Ejecutar localmente

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático.

Por ejemplo:

```bash
python -m http.server 8080
```

Después visita `http://localhost:8080`.
